Bill Hive — External API Reference Dev only

This is the contract the app's gateway (src/api/api.js) calls when the "Use external API" toggle in Settings is switched on. Implement each route below against your own backend at the base URL set in VITE_API_BASE_URL. All request/response bodies are JSON. This page is generated documentation — it is not wired to live data.

How the gateway maps calls: Most stores hold a single record keyed by "value" (mirroring the current IndexedDB layer), so GET /{store} returns that one record/array and PUT /{store}/value replaces it wholesale. authTokens is the exception — it's keyed per-token. Every route below is prefixed with your configured base URL, e.g. http://localhost:4000/api.
