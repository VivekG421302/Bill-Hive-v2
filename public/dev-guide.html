1 API Route Documentation

All routes are relative to your configured baseUrl (e.g. http://localhost:4000/api). The frontend api.js gateway adds the Authorization: Bearer <token> header automatically when VITE_API_KEY is set. JWT auth routes issue their own tokens on login.

🔑 Auth

POST /auth/register Create a new user account
Request Body
{ "username": "string", "password": "string", "name": "string", "email": "string" }
Response 201
{ "token": "jwt-string", "user": { "id": 1, "username": "...", "name": "...", "email": "..." } }
POST /auth/login Authenticate and receive a JWT
Request Body
{ "username": "string", "password": "string" }
Response 200
{ "token": "jwt-string", "user": { "id": 1, "username": "...", "name": "...", "email": "..." } }
POST /auth/logout Invalidate the current token (requires Bearer token)
Response 204
// No body
GET /auth/verify Verify token validity
Response 200
{ "valid": true, "expiresAt": "ISO-date" }

2 Database Entities & Tables
